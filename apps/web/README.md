# Frontend PWA y WebGL (apps/web)
Aplicación web móvil-primero con React, Vite, Tailwind CSS y Radix UI.
- PWA instalable con persistencia de carrito en localStorage mediante Zustand.
- Sincronización de estado con TanStack Query v5.
- Componentes WebGL acelerados bajo demanda: Visor 3D del bulto (Three.js/R3F) y Mapa de impacto de precios (regl), con fallback automático a 2D accesible.
